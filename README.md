# 새마을금고 학습 · RC4 v0.14

## 핵심 학습 구조
1. **1단계 · 5분 문제 5문항 — 반드시 완료**
2. **2단계 · 집중학습 — 기본 하루 20문항 이상**
3. 실전 모의고사는 별도 시험 흐름

집중학습 버튼·Daily 선택·학습지도 진입 등 어떤 경로를 사용해도 1단계를 완료하지 않으면 집중학습으로 바로 들어갈 수 없습니다.

## 문제 분리
- 전체 문제은행: 240문항
- 5분 문제 전용: 52문항
- 집중학습 전용: 188문항
- 두 문제군 교집합: 0문항

## 집중학습 분량
- 기본값: **20문항**
- 선택값: 20 / 25 / 30 / 40문항 / 남은 전체
- 한 Daily의 남은 문항이 목표보다 적으면 다음 Daily로 이어서 목표를 채웁니다.

## PHONE 영구 UI 원칙
- PHONE은 **카카오톡 계열 시각언어**를 기준 디자인으로 유지합니다.
- 기본 팔레트: 노랑 `#FEE500`, 갈색 `#3C1E1E`, 대화 배경 청회색 `#B2C7D9`, 수신 말풍선 흰색.
- 홈 / 학습허브 / 5분 문제 / 집중학습 / 완료 / 모의고사 / 기록까지 같은 시각언어를 사용합니다.
- 기능 추가 시 초록색 업무형 카드 테마로 되돌리지 않습니다.

## INTRANET 영구 UI 원칙
- 사내 인트라넷 PC는 **전면 회색조**만 사용합니다.
- 외부 CDN·웹폰트·네트워크 의존성 없이 동작해야 합니다.
