## v0.23에서 반영한 제언
1. **정답 위치 규칙 제거**: 300문항의 보기·보기별 사유·정답 위치를 문항 ID 기반 결정론적 순서로 재배열했습니다. 동일 문항은 항상 같은 보기 순서를 유지합니다.
2. **모의고사 재구성**: Focus 전용 20문항, Quick 중복 0, 전체 11개 영역 커버, 20개 서로 다른 개념으로 구성합니다.
3. **허위 숙달 방지**: 동일 문제 재정답 또는 단일문항 개념만으로는 MASTERED 승격이 되지 않습니다.
4. **레이어드 패치 정리**: 중복 function 선언을 제거하고 각 함수의 유효 정의를 하나로 통합했습니다.
5. **진입 파일 정리**: `index.html` 하나만 버전 선택 진입점으로 사용합니다. 오래된 C18 링크를 제거하고 `C23_DEVICE_SELFTEST.html`을 포함했습니다.
6. **빌드 규칙 문서화**: CSV(1-based answer) ↔ HTML JSON(0-based answer), 결정론적 보기 재배열, Mock ID 선발 규칙을 인계문서에 기록했습니다.
