# 새마을금고 학습 · RC4 v0.16

## 핵심 학습 구조
1. **1단계 · 5분 문제 5문항 — 반드시 완료**
2. **2단계 · 집중학습 — 기본 하루 20문항 이상**
3. 실전 모의고사는 별도 시험 흐름

## 문제·Daily 구조
- 활성 문제: **260문항**
- Master DB: **300문항**
- 5분 문제 전용: 52문항
- 집중학습 전용: 208문항
- 집중학습 Daily: **5개**, 평균 약 40문항

## PHONE 영구 UI 원칙
- PHONE은 카카오톡 계열 시각언어를 기준 디자인으로 유지합니다.
- 노랑 `#FEE500`, 갈색 `#3C1E1E`, 청회색 대화 배경 `#B2C7D9`, 말풍선형 카드 구조를 유지합니다.

## INTRANET 영구 UI 원칙
- 사내 인트라넷 PC는 **전면 회색조**만 사용합니다.
- 외부 CDN·웹폰트·API·네트워크 의존성 없이 동작합니다.
- PHONE과 동일한 핵심 아키텍처인 **홈 / 학습 / 모의고사 / 기록** 메뉴를 항상 사용할 수 있어야 합니다.

## v0.16 핵심 수정
900px 이상 사내 화면에서 기존 CSS가 `.desktop-side,.tabs{display:none!important}`를 적용하여 핵심 네비게이션이 사라지는 원인을 확인했습니다.

v0.16에서는 사내 메인 패널 안에 상시 네비게이션을 추가했습니다.

`홈 | 학습 | 모의고사 | 기록`

문제·해설 화면에서도 이 메뉴는 유지되며 기존 `data-nav` 라우터를 그대로 사용합니다.

공식 원자료 PDF는 공개 저장소에 올리지 않습니다.
