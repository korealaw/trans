# 새마을금고 전환직 학습 웹앱

모바일 중심 문제학습 웹앱입니다. 공식 자료 10종을 기준으로 문제 -> 단계별 해설 -> 공식 근거 -> 복습 흐름으로 구성합니다.

## 현재 버전
- RC3 v0.9.1
- 240문항 / 48 Concepts / 50 active Daily / 모의고사 20문항
- PHONE / PERSONAL PC / INTRANET PC 3종

## 파일
- `index.html`: 버전 선택
- `01_PHONE.html`: 모바일 중심 버전
- `02_PERSONAL_PC.html`: 개인 PC 버전
- `03_INTRANET_PC.html`: 사내 PC 오프라인 버전
- `C9_DEVICE_SELFTEST.html`: 기기별 자체 점검

## C9.1 수정 원칙
- 조문 번호 자체를 맞히는 문제를 지양합니다.
- 기간, 비율, 금액, 인원, 등급, 주체, 공식 핵심용어를 짧은 객관식으로 묻습니다.
- 전문 직함은 관련 조문에서 직접 학습할 때만 사용하며, 무관한 오답 보기로 재사용하지 않습니다.
- `감사위원장`은 실제로 새마을금고중앙회에 존재하는 공식 직함이지만, 금고 설립·정관변경인가 등 무관한 문제의 오답 보기에서는 제거했습니다.
- INTRANET PC는 메신저/카카오톡 시각언어를 제거하고 중립적인 회색·흰색 업무형 UI를 사용합니다.
