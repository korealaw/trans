# 새마을금고 전환직 학습 웹앱

모바일 중심 문제학습 웹앱입니다. 공식 자료 10종을 기준으로 하나의 검증된 문제은행을 Quick / Focus / Exam 3개 학습경로에서 공통 사용합니다.

## 현재 후보 버전
- RC4 v0.10
- 240문항 / 48 Concepts / 50 active Daily / 모의고사 20문항
- PHONE / PERSONAL PC / INTRANET PC 3종

## RC4 구조
- **Quick**: 5분 빠른학습. 취약문항과 다음 미학습 문항을 우선하여 5문항을 바로 풉니다. 정답 후 한 줄 핵심만 기본 노출하고, 이유와 공식 근거는 필요할 때 펼칩니다.
- **Focus**: 기존 Daily 집중학습. 단계별 해설, 보기별 판정, 공식 근거, 마인드맵을 유지합니다.
- **Exam**: 20문항 실전 모의고사. 제출 전 정답 비공개, 제출 후 순차 해설합니다.
- 세 경로는 같은 `questionStats`와 localStorage 학습기록을 사용합니다.
- Daily 완료 판정은 Focus에 유지하여 빠르게 본 문항과 집중학습 완료를 구분합니다.

## UI 원칙
- 첫 화면에는 Quick / Focus / Exam / 기록만 노출합니다.
- 세부 학습범위, 분량조절, 학습지도, 백업은 한 단계 안쪽에 둡니다.
- 하단 메뉴는 홈 / 학습 / 모의고사 / 기록 4개입니다.
- INTRANET PC는 외부 의존성 없이 중립 회색 업무형 UI를 유지합니다.

## 원자료 취급
원자료 PDF 10종은 공개 GitHub 저장소에 업로드하지 않습니다. 저장소에는 실행 앱과 QA/인계 문서만 둡니다.
