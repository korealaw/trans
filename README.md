# 새마을금고 학습 · RC4 v0.12

## 핵심 학습 구조
오늘 학습은 선택형 병렬 구조가 아니라 **필수 순차 구조**입니다.

1. **1단계 · 5분 문제 5문항 — 반드시 완료**
2. **2단계 · 집중학습 — 기본 하루 20문항 이상**
3. 실전 모의고사는 별도 시험 흐름

집중학습 버튼·Daily 선택·학습지도 진입 등 어떤 경로를 사용해도 1단계를 완료하지 않으면 집중학습으로 바로 들어갈 수 없습니다.

## 문제 분리
- 전체 문제은행: 240문항
- 5분 문제 전용: 52문항
- 집중학습 전용: 188문항
- 두 문제군 교집합: 0문항

## 집중학습 분량
- 기본값: **20문항**
- 선택값: 20 / 25 / 30 / 40문항 / 남은 전체
- 시간 설정도 최소 약 20문항부터 시작
- 한 Daily의 남은 문항이 목표보다 적으면 다음 Daily로 이어서 하루 목표를 채움

## UI 영구 원칙
- 제품명은 **새마을금고 학습**으로 통일
- 사내 인트라넷 PC 버전은 **전면 회색조**만 사용
- 사내판은 외부 CDN·웹폰트·네트워크 의존성 0
- 구조도형 기반 별도 마무리 학습 기능은 사용하지 않음
